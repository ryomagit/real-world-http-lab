# HTTP/1.1のシンタックス

『Real World HTTP 第3版』第5章「HTTP/1.1のシンタックス：高速化と安全性を求めた拡張」の学習用ディレクトリ。

## 概要

HTTP/1.1で導入された仕組みを、Goのサンプルコードや`curl`を使って実際に確認する。

## 主なテーマ

- Keep-Aliveとパイプライニング
- TLS
- PUT、DELETE、OPTIONS、TRACE、CONNECT、PATCH
- プロトコルのアップグレード
- バーチャルホスト
- チャンク転送とコンテンツ送信の確認
- データURIスキーム

## 学習方針

1. 書籍のサンプルコードを実装する
2. リクエストとレスポンスの内容を確認する
3. HTTP/1.0とHTTP/1.1の違いを整理する
4. 高速化や安全性のための仕組みが通信へ与える影響を検証する
5. 学んだことや注意点をこのREADMEへ記録する

## ディレクトリ構成

実行可能なサンプルごとにサブディレクトリを作成する。

```text
02-http11-syntax/
├── README.md
└── <sample-name>/
    └── main.go
```

## 実行方法

リポジトリ直下の`go.mod`を利用するため、このディレクトリで`go mod init`を実行する必要はない。

リポジトリ直下から、実行するサンプルを指定する。

```bash
go run ./02-http11-syntax/<sample-name>
```

## 学習メモ

サンプルを追加したら、確認したHTTPヘッダー、通信内容、HTTP/1.0との違いなどをここへ追記する。
